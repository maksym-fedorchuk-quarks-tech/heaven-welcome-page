About the project

A free API inspired by the Preacher universe.
No key, no sign-up, nothing stored: the data is generated on the fly.

Heaven's Data is a practice playground for students, educators and developers who need a small, friendly API for tutorials, pet projects and test tasks. It is not a retelling of the series: it borrows characters and places and turns them into data you can page through, filter and load in bulk.

The API does not collect anything about you. There are no accounts and no tokens, and requests are not logged by the API code. Souls are generated fresh on every request; characters and locations are a small fixed catalog.

Docs

Base URL: https://heavensdata.com/api. All endpoints are GET and return JSON. CORS is open, so you can call the API straight from a browser.

Characters

GET /characters

Paged list, 10 per page. Filters: name (contains), status (Alive, Dead, unknown), species, gender, and page.
https://heavensdata.com/api/characters?status=Alive&page=1

The response has the same shape as the Rick and Morty API: { "info": { "count", "pages", "next", "prev" }, "results": [ ... ] }.

GET /characters/{id}

One character, or several at once with comma-separated ids.
https://heavensdata.com/api/characters/1,2

Locations

GET /locations and /locations/{id}

Heavens areas (Registration Gate, Pray Fields, Magic Forest, Dormitory, Observational Cloud, All Saints Church) and places from the wider universe. Filters: name, type, realm (Heavens, Earth, Hell), page.
https://heavensdata.com/api/locations?realm=Heavens

Souls

Souls are generated, not stored. Each soul has an id, a name, a location and a status. Every request returns different souls.

GET /souls

A short list, up to 20 souls (count, default 20). Filters: location (a location id) and status: registered, in_transit, wandering, praying, resting, watching, lost.
https://heavensdata.com/api/souls?location=4&status=resting

GET /souls/batch

A batch of exactly 100 generated souls per call, with the same location and status filters. Each requester gets a limited number of batches per hour; the headers X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset (seconds) show what is left. When the limit is reached the API answers 429 with a Retry-After header.
https://heavensdata.com/api/souls/batch?status=praying

Errors

Errors look like { "error": "..." }. 400 is a bad parameter, 404 means nothing matched (There is nothing here), 405 is any method other than GET, 429 is the batch limit.

Good to know

  • Character statuses are part of the API fiction and may differ from the series.
  • The limit is best effort and may be loose; please be kind to the service.
  • Heaven's Data is an unofficial fan project. It is not affiliated with, or endorsed by, the creators or producers of Preacher.
