Examples

This API returns raw (as-happen) daily events (datetime, event_name, soul_id, event_location, context, meta) of the registered events from variety locations, covering 20+ weeks of historical data.

API Parameters

  • Required apikey
    Your API key. Claim your free API key here
  • Optional date_from
    By default, parameter is equal to the yesterday's date. The limit is set to yesterday's date minus 21 days;
  • Optional date_to
    Defaults to the current date. Note that the API does not support future dates, in accordance with our celestial policy;

GET /registrations events

Gates and registration funnel. In order to access all the magnificent areas that Heaven has to offer, it is essential for soul to provide her personal data and register at the gate. No insurance details or email needed - here you can proceed without any concerns about those details.
https://www.example.com/query/registrations?date_from=2025-05-01&apikey=[your_api_token]

The central area. Named by people who have never been here. Typically, no one prays here. It’s simply a vast festival ground - the primary gathering spot.
https://www.example.com/query/pray_fields?date_from=2025-05-01&apikey=[your_api_token]

https://www.example.com/query/dormitory?date_from=2025-05-01&apikey=[your_api_token]
