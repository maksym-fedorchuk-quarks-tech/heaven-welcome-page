What is all about

Heavens API serves a small catalog of characters and locations from a Preacher-inspired universe
and generates lists of souls, with their locations and statuses, on the fly
No key, no sign-up, nothing stored
It's free and open

Start in one request

There is nothing to sign up for. Just call it:

curl https://heavensdata.com/api/characters?name=jesse

curl https://heavensdata.com/api/souls/batch

  • Read the docs

Who might be interested in that API

Whether you're a student, a pet project developer, an interviewer searching for a test task dataset, or an educator, Heaven's Data is your open data source for practicing real API work: paging, filtering, rate limits and bulk loading.
Characters and locations are a small fixed catalog. Souls are generated fresh on every request, so you can pull as many as the limits allow without anything ever being stored about you.

Heaven's Data is an unofficial fan project. It is not affiliated with, or endorsed by, the creators or producers of Preacher.
